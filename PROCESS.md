# Process

## Starting idea

I wanted to make a small, silly personality quiz that gives someone a quick break and a funny potato character as a result.

## Design changes

I used AI to help write the first version of the Python and Streamlit code. After reviewing it, I asked for one question to appear at a time and for the next question to appear after an answer, instead of presenting the experience as a conventional questionnaire. I also felt the first wording was too serious, so I asked for more absurd, playful copy. The project then added a falling-answer animation, optional collectible potato stamps, and illustrated results.

## AI use

I used ChatGPT/Codex to help draft and revise the code, interface copy, animation, and this documentation. I kept the proposed falling-answer animation and stamp-collecting bonus. I changed the initial questionnaire-like interaction into a one-question-at-a-time flow, and revised the more serious wording into absurd humour based on my feedback.

## User trial
